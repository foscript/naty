# Create a project
Everything starts here on this page, Naty.
Building on the Quick Start, I will explain things in greater detail on this page.

<br/>

## How to create Naty project with official template?
1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use official template`.
3. Please find and select the template you wish to create from [Templates](/templates).
4. When you select a template, you will configure the settings specific to that template.
5. Once completed, a log will be displayed and the process will finish. Please navigate to the desired directory and begin development.

<br/>

## Can I specify options all at once?
Yes, as long as the option values are correct, Naty will handle it automatically. I have included some examples of how to specify options here.

Example
- `npm create naty@latest -option <OPTION1> <OPTION2> <OPTION3>`
- `npm create naty@latest -option official <OFFICIAL_TEMPLATE_ID> Naty`

<br/>

## So, what about third-party templates?
That makes sense :)

In Naty, the method for creating a project is largely the same, but the key is `where` you get the template from.

There are two ways to use third-party templates.
- Get the template from `GitHub`
- Get the template from `Web`

<br/>

## Warning
Third-party templates `have not been verified!` Be sure to check the scripts that will be executed, or use templates from trusted developers.

<br/>

## Case GitHub
This approach is likely simpler and easier to understand, and it is also easier for developers to implement.

Let me show you how to use a template from GitHub.

1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use third-party template`.
3. You will be asked how you want to obtain the template, so please select `Use GitHub`.
4. Please enter the template ID which is actually just a combination of the username and repository name. The developers likely have it displayed somewhere easy to find, or it appears as part of a command.
4. When you enter the template ID, you will configure the settings specific to that template.
5. Once completed, a log will be displayed and the process will finish. Please navigate to the desired directory and begin development.

<br/>

## Case Web
This method retrieves a template from the web.

1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use third-party template`.
3. You will be asked how you want to obtain the template, so please select `Use Web`.
3. Please enter the template URL. The developer may have displayed this in an easily accessible location or provided it as a command.
4. When you enter the template URL, you will configure the settings specific to that template.
5. Once completed, a log will be displayed and the process will finish. Please navigate to the desired directory and begin development.
