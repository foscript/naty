# Create a project
Here, I will explain things in greater detail than in the Quick Start.

<br/>

## How to create Naty project with official template?
1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use official template`.
3. Please find and select the template you wish to create from [Templates](/templates).
4. When you select a template, please configure the settings specific to that template.
5. Once creation is complete, the log will appear, and you can start development right away!

<br/>

## Can I options all at once?
Yes, if you configure it correctly as shown in the example below, it will be created automatically.

Basic Example
- `npm create naty@latest -option <OPTION1> <OPTION2> <OPTION3>...`

Official Template
- `npm create naty@latest -option official <TEMPLATE_ID> <OPTIONS>...`

<br/>

## So, how about third-party templates?
Oh, I had forgotten about that. :)

There are primarily two ways to use third-party templates.
- Get the template from `GitHub`
- Get the template from `Web`

<br/>

## Warning
Third-party templates `have not been verified!` Be sure to check the scripts that will be executed, or use templates from trusted developers.

<br/>

## Case GitHub
1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use third-party template`.
3. You will be asked how you want to obtain the template, so please select `Use GitHub`.
4. Please enter the template ID which is actually just a combination of the username and repository name like "foscript/naty".
5. Switch to the fourth official template.

<br/>

## Case Web
1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use third-party template`.
3. You will be asked how you want to obtain the template, so please select `Use Web`.
3. Please enter the template URL.
4. Switch to the official template
