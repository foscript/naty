# Create a project
Everything starts here on this page, Naty.
Building on the Quick Start, I will explain things in greater detail on this page.

<br/>

## How to create Naty project with official template?
1. Run `npm create naty@latest`
2. You will be asked how to create the project, so select `Use official template`.
3. Please find and select the template you wish to create from [Templates](/templates).
4. When you select a template, you will configure the settings specific to that template.
5. Once completed, a log will be displayed and the process will finish. Please navigate to the desired directory and begin development.
