# Getting Started
Welcome to Naty Docs!

<br/>

## What is Naty?
- This tool allows you to create a new project using your favorite templates.
- You can skip tedious settings and start development immediately.

<br/>

## Quick Start
1. Run `npm create naty@latest`
2. Configure project settings.
3. Run `cd "Project Name"` to move to the project directory.
4. Run `npm run dev` to start develop!
